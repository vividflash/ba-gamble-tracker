# BA Gamble Loot

Records the rewards from Barbarian Assault low and medium gambles in the Loot
Tracker.

## Gamble Settings

Block eats the click on that row and on Accept. Highlight only outlines it.

| Setting | Default |
| --- | --- |
| Low gamble | Off |
| Medium gamble | Off |
| High gamble | Off |

## Diagnostics

| Setting | Default | Prints |
| --- | --- | --- |
| Only use the accept path | On | Nothing, drops the honour point fallback |
| Unexpected charge | On | Charges that differ from the listed price |
| Blocked clicks | On | Clicks a guard ate |
| Gamble detection | On | Accept clicks, the row read, points spent |
| Rewards | On | Loot paid out, or none arriving |
